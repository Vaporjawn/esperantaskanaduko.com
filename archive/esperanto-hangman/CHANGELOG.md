# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Automated deployment to GitHub Pages and Surge
- Pull request template for contributors
- Security policy documentation
- Dependabot configuration for automated dependency updates
- Funding configuration for GitHub Sponsors
- Comprehensive badges in README

### Changed
- Enhanced README with deployment links and better formatting
- Improved GitHub Actions workflow with PR previews

## [1.0.0] - 2025-10-19

### Added
- Initial release of Esperanto Hangman
- Full support for all 28 Esperanto letters including diacritics (ĉ, ĝ, ĥ, ĵ, ŝ, ŭ)
- X-notation input support (cx → ĉ, gx → ĝ, etc.)
- Virtual Esperanto keyboard with click support
- Physical keyboard support
- 250+ Esperanto words database
- Game statistics tracking (games played, wins, streak)
- LocalStorage persistence
- Material-UI based responsive design
- Full WCAG accessibility compliance
- Dark/Light theme support
- Comprehensive documentation
- Contributing guidelines
- Code of Conduct
- Issue templates
- MIT License

### Technical
- React 19 + TypeScript
- Vite 7 with Rolldown
- Material-UI v7
- Zustand state management
- ESLint + Prettier
- GitHub Actions CI/CD
